AI Docs Chatbot

RAG-Powered Support Automation

Challenge

Long documentation was hard to search and a general LLM would hallucinate answers instead of admitting it didn't know — with no escalation path for unresolved queries after hours.

Engineering Solution

Built two n8n pipelines: one chunks and embeds documentation into Supabase/pgvector, the other runs a LangChain RAG chain over GPT-4o-mini for grounded, source-cited answers, escalating unresolved queries to Microsoft Teams.

Key Result

Delivered a zero-hallucination, source-cited support chatbot with 24/7 coverage and automated human escalation for every unresolved query.
